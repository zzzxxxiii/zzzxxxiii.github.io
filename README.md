# 曾鑫 · 个人网站

最新版个人作品集：影像作品、工作经历、摄影与随手拍。

## 网站

GitHub Pages 配置完成后的地址： https://zzzxxxiii.github.io/

## 本地浏览

双击 `启动预览.cmd`，或使用 Python 3 运行 `python preview.py`。
所有网页素材保存在 `assets/` 中；完整视频入口链接到飞书。

## 部署

这是无需构建的 HTML/CSS/JavaScript 网站。
GitHub Pages 使用 `main` 分支的根目录 `/` 发布，`.nojekyll` 用于直接发布静态文件。

## 主要文件

- `index.html`：首页
- `photography.html`：摄影图库
- `works.js` / `photos.js` / `mobile.js`：作品内容
- `app.js` / `home.js` / `gallery.js`：交互逻辑
- `profile.css`：最新视觉样式
- `assets/fonts/OFL.txt`：字体许可
